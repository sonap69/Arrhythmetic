**Αρρυθμομηχανή / Arrhythmetic**: a desktop drum machine with 10 synthesized voices, odd time signatures, velocity, five effects, MIDI input and WAV/MIDI export.

### Download and run (Windows 10/11, 64-bit)

1. Download the `.exe` under **Assets** below.
2. Run it. There is nothing to install.
3. Windows may say **"Windows protected your PC"**, because the app isn't code-signed (a signing certificate costs money every year, which a free hobby project skips). Click **More info**, then **Run anyway**.

Saved patterns go to `%APPDATA%\Arrhythmetic\Patterns`. The [README](https://github.com/sonap69/Arrhythmetic#readme) explains how to use it and how to build it from source.
